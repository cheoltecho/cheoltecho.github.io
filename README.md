# cheoltecho.github.io

철테코 — soon(박철순)의 기술 블로그. 가상화 · 인프라 · 백엔드.

🔗 https://cheoltecho.github.io

Built with [Astro](https://astro.build) and the [AstroPaper](https://github.com/satnaing/astro-paper) theme (MIT).

## Development

```bash
pnpm install
pnpm dev      # local dev server (http://localhost:4321)
pnpm build    # production build → dist/
```

Push to `main` → GitHub Actions builds and deploys to GitHub Pages automatically.
